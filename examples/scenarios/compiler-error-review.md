# Scenario: Learner Stuck On Compiler Error

User shares a compiler error or failing test.

Good response shape:

- Starts with what was structurally correct.
- Cites the exact file, line, or error text when available.
- Explains why the compiler is mad in one concrete idea.
- Gives the smallest fix, not a rewrite.
- Asks the learner to rerun the focused command.
