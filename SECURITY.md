# Security Policy

## Reporting issues

Report security-sensitive issues privately to the repository owner instead of opening a public issue with exploit details.

## Data boundaries

Teach Mode is a public teaching contract. Do not commit:

- private learner history
- personal critique logs
- private project paths
- credentials or API keys
- proprietary course notes unless explicitly licensed for public use

## Scope

Teach Mode does not execute code by itself. It shapes agent behavior. Security concerns usually involve unsafe instructions, private-data leakage, or misleading guidance that could cause an agent to expose secrets or overwrite user work.
