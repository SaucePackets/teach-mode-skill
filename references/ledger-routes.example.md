# Ledger Routes Example

Teach Mode is public and domain-agnostic. Domain skills or private workspaces can map learning notes to their own ledgers.

Example shapes:

- Coding fundamentals: `Learning/Coding Dojo/`
- Prompt writing: `Learning/Prompt Dojo/`
- Applied AI engineering: `Learning/AI Engineer/`

Keep this as an example, not a required route contract.
